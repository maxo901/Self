MAXO SELF WEB — راهنمای اجرا روی Railway

1) همه فایل‌ها را در یک Repository آپلود کن.
2) Railway را به Repository وصل کن. Start Command:
   uvicorn app:app --host 0.0.0.0 --port 8080
3) در Railway برای سرویس یک Volume بساز و Mount Path را دقیقاً /app/data قرار بده.
   بدون Volume ممکن است سشن‌ها و دیتابیس پس از دیپلوی از بین بروند.
4) در Settings > Networking برای سرویس دامنه بساز و پورت داخلی 8080 را انتخاب کن.
5) Deploy کن. رمز مدیریت اولین بار در Deploy Logs با عنوان ADMIN PASSWORD چاپ می‌شود.
6) وارد سایت شو. API ID و API HASH را در بخش اکانت‌ها وارد کن. از my.telegram.org بخش API development tools دریافت می‌شوند.
7) شماره را با + و کد کشور وارد کن، کد تلگرام یا ایمیل را بزن و اگر خواست رمز دومرحله‌ای را وارد کن.
8) برای افزودن اکانت دیگر همین مراحل را تکرار کن.

نکته‌های مهم:
- Telegram API ID و API HASH اجباری‌اند؛ نمی‌توان بدون آن‌ها با Telethon وارد حساب شد. در این نسخه نیازی به Railway Environment Variables نیست.
- کد ورود فقط برای تکمیل لاگین استفاده می‌شود. رمز دومرحله‌ای ذخیره نمی‌شود. سشن ورود در data/accounts نگهداری می‌شود؛ این فایل‌ها معادل دسترسی کامل به حساب هستند و باید محرمانه بمانند.
- هر حساب یک worker و دیتابیس جدا دارد.
- پنل روی پورت 8080 اجرا می‌شود.
- برای جلوگیری از از دست رفتن دیتا، Volume را نگه دار و پوشه /app/data را پاک نکن.
- بخش چت‌ها جستجوی رکوردهای دریافتی ذخیره‌شده در جدول chats است؛ تاریخچه کامل تمام پیام‌های قدیمی تلگرام را دانلود نمی‌کند.
- آرشیو حذف‌شده‌ها فقط پیام‌هایی را نشان می‌دهد که در زمان دریافت قابلیت آرشیو روشن بوده و رویداد حذفشان توسط تلگرام به کلاینت رسیده باشد. فایل‌های رسانه‌ای آرشیو مطابق منطق نسخه اصلی ممکن است بعد از ۲۴ ساعت پاک شوند.
- اگر تلگرام مرحله تأیید ایمیل جداگانه یا محدودیت ورود جدید نشان دهد، این نسخه ممکن است نیازمند تکمیل دستی همان مرحله در برنامه رسمی تلگرام باشد.
- از این پروژه فقط برای حساب‌هایی استفاده کن که مالکشان هستی یا اجازه مدیریت آن‌ها را داری.
