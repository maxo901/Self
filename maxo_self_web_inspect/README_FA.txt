MAXO SELF WEB — نسخه کامل پنل مدیریتی Railway

راه‌اندازی:
1) تمام فایل‌های داخل ZIP را در ریشه Repository گیت‌هاب قرار بده (فایل‌ها داخل یک پوشه اضافه نباشند).
2) Repository را به Railway وصل و Deploy کن.
3) برای ماندگاری اطلاعات، یک Railway Volume بساز و Mount Path را دقیقاً /app/data قرار بده.
4) در Settings > Networking یک دامنه بساز و Target Port را 8080 انتخاب کن.
5) سرویس را Deploy کن. هیچ Environment Variable برای شروع وب‌سایت لازم نیست.
6) با رمز اولیه admin وارد پنل شو و از تنظیمات، رمز مدیریت را به یک رمز قوی تغییر بده.
7) برای ورود حساب تلگرام، API ID و API HASH معتبر را فقط یک‌بار از داخل سایت ثبت کن. سپس شماره با کد کشور، کد ورود و در صورت درخواست رمز دومرحله‌ای را وارد کن.

قابلیت‌های پنل:
- داشبورد آمار اکانت‌ها، چت‌ها، پیام‌های آرشیوشده، پاسخ‌ها و وضعیت Workerها.
- افزودن چند حساب تلگرام، شروع/توقف و حذف حساب.
- جستجوی چت‌های ثبت‌شده با آیدی عددی، یوزرنیم و نام.
- بلاک، آنبلاک، سکوت و لغو سکوت کاربران.
- حذف تعداد مشخصی از پیام‌های اخیر یک گفتگوی خصوصی یا حذف یک پیام با شناسه پیام.
- موتور پاسخ خودکار با فعال/خاموش، ویرایشگر قالب‌دار (بولد، ایتالیک، زیرخط، نقل‌قول و لینک) و سه استایل اصلی؛ محدودیت اصلی هر مخاطب یک پاسخ در ۱۰ دقیقه حفظ شده است.
- آرشیو پیام‌های حذف‌شده، اطلاعات فرستنده، زمان و دسترسی به فایل رسانه‌ای ذخیره‌شده.
- ساعت در نام و بیو، انتخاب چهار فونت، برچسب دلخواه و بازگردانی مقدار قبلی.
- انتقال محتوای کانال/گروه/چت به Saved Messages، محدودیت تعداد، شروع از ابتدا، ادامه از نقطه ذخیره‌شده و توقف.
- ارسال تکراری به Saved Messages تا ۳۰ بار، تنظیم فونت پیام‌های PV، گزارش وضعیت، اطلاعات اکانت و لاگ Worker.
- تغییر رمز مدیریت از داخل پنل.

نکات مهم:
- Telegram API ID و API HASH از نظر فنی برای اتصال Telethon اجباری‌اند و قابل حذف نیستند؛ اما نیازی به تعریف آن‌ها در Railway Variables نیست و فقط در پنل سایت ذخیره می‌شوند.
- رمز اولیه پنل admin است. آن را بلافاصله تغییر بده.
- کد ورود فقط برای ورود استفاده می‌شود و رمز دومرحله‌ای ذخیره نمی‌شود. فایل Session دسترسی کامل به حساب دارد؛ Volume و فایل‌های /app/data را محرمانه نگه دار.
- هر حساب Worker و دیتابیس جداگانه دارد.
- دامنه Railway باید به پورت داخلی 8080 متصل باشد.
- بدون Volume ممکن است پس از Deploy یا جابه‌جایی سرویس، سشن‌ها و دیتابیس از بین بروند.
- جستجوی چت، رکوردهایی را نشان می‌دهد که ربات از زمان فعال بودن در جدول chats ذخیره کرده؛ تاریخچه کامل چت‌های قدیمی تلگرام را خودکار دانلود نمی‌کند.
- آرشیو حذف‌شده‌ها فقط پیام‌هایی را نشان می‌دهد که هنگام دریافت کش شده‌اند و رویداد حذفشان به کلاینت رسیده است. کش پیام‌های حذف‌نشده مطابق نسخه اصلی پس از ۲۴ ساعت پاک می‌شود.
- مرحله تأیید ایمیل مستقل یا محدودیت ورود تلگرام ممکن است به تأیید جداگانه در برنامه رسمی نیاز داشته باشد.
- از این پنل فقط برای حساب‌هایی استفاده کن که مالکشان هستی یا مجوز مدیریت آن‌ها را داری.

Start command:
uvicorn app:app --host 0.0.0.0 --port 8080
